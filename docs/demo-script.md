# Demo script (target: under 3 minutes)

1. Introduce Cairn as an emergency-preparedness copilot that keeps essential guidance available offline.
2. Enter a sample household and review the extracted profile.
3. Generate the rules-based 72-hour kit; show the reason for a quantity and the actual engine badge.
4. Enable airplane mode. Ask a guide-grounded question and show its source and actual inference engine.
5. If cloud queueing is implemented and verified, demonstrate a queued request and replay after reconnecting.
6. Play a simulator decision, then show the editable SOS draft and disclaimer.
7. Show read-aloud, larger text and simplified language.
8. End with the router, App Check and Remote Config architecture.

Only demonstrate behaviors verified on the recorded device. Seeded household: two adults, one infant, insulin storage need, one dog.

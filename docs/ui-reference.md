# Cairn visual reference

The current design is [Personalised 72-Hour Kit Journey](../app/docs/Personalised%2072-Hour%20Kit%20Journey.png).

Use navy headers, a rounded light content area, teal progress, purple feature icons and the orange SOS action. Home shows a mountain wordmark, household readiness, four shortcuts and the Home, Assistant, Kit and More tabs. My Household shows members, pets, medical needs and accessibility, with a separate voice entry point. Its saved profile feeds the offline kit.

The kit opens with a household summary, a readiness ring and four category cards. Each category opens its own checklist with calculated targets and explanations. Use real counts instead of the values illustrated in the reference. The drinking-water rule remains six liters per person for 72 hours, with the duration made explicit.

The SOS screen adds an orange Talk to Cairn action above the three reference cards for Get Help, Offline Guidance and Rescue Card. The microphone beside Emergency SOS on Home opens Voice SOS directly. Keep essential SOS actions independent of the network and AI. The Assistant, Simulator and Accessibility screens use the same visual hierarchy and support the app language. English remains the default.

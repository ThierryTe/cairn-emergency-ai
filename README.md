# Cairn

**Emergency copilot, on-device first.**

Cairn is an offline-first, accessibility-focused emergency preparedness application designed to help households prepare for unexpected situations and access essential guidance when connectivity is limited.

Built for the Google Firebase #BuildHybridAI Hackathon, Cairn explores hybrid AI using Firebase AI Logic, combining on-device intelligence where supported with cloud-based assistance.

### Planned Features

- **Smart Household Profiles:** Describe household needs in natural language and review structured information.
- **Personalized 72-Hour Kits:** Build and track emergency supplies based on household size and specific needs.
- **Hybrid AI Assistant:** Access source-grounded preparedness guidance with local or cloud AI when available.
- **Adaptive Crisis Simulations:** Practice responding to emergency scenarios.
- **Emergency SOS:** Quickly access emergency calling, prepare messages, and view location information.
- **Accessibility First:** Screen reader support, voice guidance, high contrast, and simplified instructions.
- **Offline Essentials:** Keep critical checklists and verified emergency guides available without internet access.

### Technology Stack

Kotlin · Jetpack Compose · Firebase AI Logic · Gemini · Room · Material 3

### Project Status

🚧 In development — hackathon prototype.

**Safety note:** Cairn does not replace official emergency services or government alerts. AI availability depends on device compatibility and connectivity.
